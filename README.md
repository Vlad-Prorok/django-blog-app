📝 Personal Django Blog Project
Веб-приложение для публикации и чтении статей написанное на Python с использованием фреймворка Django
Функционал:
  * Регистрация и авторизация пользователей
  * Создание, просмотр, редактирование и удаление публикаций
  * Система комментирования статей
  * Маршрутизация страниц и динамическая шаблонизация HTML
